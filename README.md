# Disney+ Flutter Lab

Aplicación móvil académica de streaming inspirada en Disney+, construida con Flutter.

## Funcionalidades

- Splash de bienvenida animado y navegación con rutas nombradas.
- Inicio con banner, franquicias seleccionables y carruseles de contenido.
- Detalle de película con transición Hero, sinopsis y reparto.
- Perfil con opciones de cuenta, ajustes, tema y salida.
- Catálogo mock en listas y mapas, logos locales y pósters remotos.
- Tema oscuro con Cinzel, Inter y Oswald.

## Ejecutar

Necesitas Flutter instalado y un emulador o dispositivo conectado:

```bash
flutter pub get
flutter run
```

Para validar análisis y pruebas:

```bash
flutter analyze
flutter test
```

Los pósters usan imágenes remotas de demostración; se requiere conexión a internet para cargarlos.
